SHAUNKETSU AWARDS 2026 — STARTER SITE

FILES
- index.html: the homepage (HTML, CSS, and JavaScript are currently together here)
- assets/shaunketsu-collage.jpg: the supplied profile collage used in the hero

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open the ShaunKetsuAwards2026 folder.
3. Double-click index.html to open it in a browser.
4. The Google Fonts import needs an internet connection; the rest of the site is local.

PUBLISHING
A simple static site like this can be hosted on GitHub Pages. The site is not online yet.
See: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

NOTES
- The "peek at the future" button is a local demo, not a live publishing system.
- For real rankings that you can publish without editing HTML, we can add a small data file or a database/admin dashboard in a later step.
- Make sure you have permission to publish any character artwork you add.
